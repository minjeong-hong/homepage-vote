CJ웰케어 메인페이지 시안 — 흰 바탕 + 더스티 블루

■ 보는 방법
압축을 푼 뒤 index.html 을 Chrome 또는 Edge로 엽니다. 마우스 휠로 천천히 스크롤하세요.
영상·이미지·글꼴은 폴더 안에 있어 오프라인에서도 동작합니다.

■ 페이지
index.html     — 메인 페이지
science.html   — 사이언스(연구 근거 · 핵심 균주 · 마이크로바이옴 플랫폼 · 논문과 인증)
solutions.html — 솔루션(12개 브랜드를 출발한 연구별 · 고민별 · 가나다순으로 보기)

■ 심사위원 모드
모든 페이지 오른쪽 아래 '심사위원 모드' 버튼을 켜면, 각 구간에 공모전 가이드 1(메뉴) · 2(근거) · 3(비전) 중
무엇을 위한 구간인지 메모가 붙습니다. 같은 창에서 페이지를 옮겨도 켜진 상태가 유지됩니다.

■ 상단 메뉴
사이언스 · 솔루션 · 웰니스 · 라이브러리 · 회사. 과학적 근거를 앞세우기 위해 '사이언스'를 맨 앞에 두었고,
하위 메뉴는 연구 근거 · 핵심 균주 · 마이크로바이옴 플랫폼 · 논문과 인증으로 나눴습니다.

■ 메인 페이지 구성
1. 슬로건 — 첫 화면에 비전 문구(The K-Lifestyle Wellness Solution Provider)와 슬로건, 아래 작은 렌즈 속에서만 연구소 영상. 스크롤하면 렌즈가 열려 영상이 화면 가득 펼쳐집니다.
2. 줌아웃 · 초점 — 영상이 작아지며 흐려졌다가 초점이 맞고, 배율(×1,000 → ×1)과 눈금자(10 μm → 1 cm)가 함께 바뀝니다.
3. 과학 · 가로로 흐름 — 연구 사진과 숫자가 스크롤하지 않아도 계속 흐르고, 스크롤하면 빨라지며,
   사진·글 위에 마우스를 올리면 멈춥니다(휴대폰은 누르고 있으면 멈춤). 끝없이 이어집니다.
4. 연구 근거 — 연구 방식 · 대상 · 확인한 것 · 출처를 담은 카드 3장(전체는 사이언스 페이지).
5. 근거 연결 — CJ바이오사이언스 기술 → CJ웰케어 제품 → 고객 가치를 한 줄씩. 마지막 줄은 '다음 단계'(맞춤형 솔루션).
6. 나만의 접시 — 세 가지를 고르면 접시 속 미생물이 달라지고, 생활 습관 유형 · 맞는 브랜드 · 근거를 알려줌(이미지 저장 가능).
   상단 '나에게 맞는 관리 찾기' 버튼이 이곳으로 연결됩니다.
7. 제품 — 제품 기둥이 자동으로 흐르고, 마우스를 올리면 멈춥니다. 바이오코어 · 맥플랜은 근거(균주 · 원료)가 함께 표시됩니다.
8. 마무리 — 슬로건, 뉴스룸, 건강기능식품 고지.

■ 사이언스 페이지 구성
연구 근거(종류별 거르기) · 핵심 균주 5종 · CJ바이오사이언스 마이크로바이옴 플랫폼(데이터, 4단계, MAC) · 논문과 인증.

■ 제출 전 사내 확인이 필요한 내용
- 솔루션 페이지의 브랜드 분류(출발한 연구별)와 브랜드별 근거 표기
- 맥플랜의 MAC 식이섬유와 CJ바이오사이언스 MAC 인체적용연구의 관계(페이지에는 초안 표현대로 '마이크로바이옴 기술력을 담은'으로만 씀)
- CJLP133 인체적용시험의 대상 수와 결과 수치(받은 자료에 없어 쓰지 않음)
